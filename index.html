Where FusionHost Stops (Published Transparently)

A short, honest limitations list beats a long feature list nobody trusts. Here are our intentional architectural non-goals:

1. Single Instance Per App One container per app. No distributed load balancer pools.
2. PostgreSQL Only No managed Redis or MongoDB. Pass external credentials via env vars.
3. Ephemeral Local Disk Local disk is wiped on redeploy. Store files in S3 or database.
